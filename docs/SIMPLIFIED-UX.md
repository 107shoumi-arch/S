# 操作簡化：2026-10-29

這次改版集中在既有功能，沒有加入新的策略訊號或改寫損益模型。既有持倉、備份格式、自選與費率快照繼續沿用。

## 最常用的三個操作

- **查股票**：首頁捷徑進入自選，直接聚焦搜尋欄。以代號或名稱搜尋目前取得／匯入的資料，再點標的進入分析。
- **新增交易**：首頁可直接開啟買進表單。填代號、日期、成交價及股數；費用可在進階區核對。儲存後前往持倉查看結果。
- **風險試算**：直接開啟分析的試算區，先調整價格、股數、停損停利及可承受損失。投資預算、滑價及跳空假設在進階區，收合摘要仍會顯示目前設定。

## 第一次使用

1. 首頁新增一筆自己的買進交易，股數使用「股」，一般 1 張為 1,000 股。
2. 持倉顯示成本與目前可估算的損益。若沒有報價，依券商或官方紀錄輸入帶日期的參考價格；沒有價格時不把市值當成零元。
3. 分析頁切換「走勢／試算」，只看目前需要的內容。試算是使用者設定的情境，不是買賣建議。
4. 到設定的資料備份區匯出 JSON，保管在自己的安全位置。資料仍只在這個裝置瀏覽器，不會因介面改版而自動上傳。

## 畫面整理

- 首頁先呈現持倉損益及快捷操作，市場與自選資訊集中顯示；移除重複摘要與裝飾口號。
- 走勢與試算分開，避免為找計算器捲過長篇內容。切換後仍保留選取標的與已輸入的試算數值。
- 持倉保留均價、參考價及損益，費稅與其他細節可展開；報價日期與來源保持可見。
- 交易表單先顯示必要欄位；費用摘要可核對折扣，不因收合而忽略手續費。
- 設定分組呈現外觀、資料、交易成本、安裝及關於，降低第一次看到的資訊量。

## 資料正確性補強

- 台北凌晨匯入當日日期，不再誤判為未來資料。
- 指數解析跳過空列、負值及未來日期；來源缺漏時保留舊指數及原日期，明確標記快取。
- 全部來源失敗且沒有可用資料時，30 秒後允許重新嘗試；有資料時仍維持 15 分鐘擷取節奏。

## 限制
