# iPhone 15 Pro Max UI/UX 品質檢查

2026-10-28，主要視窗 **430×932 CSS px**；Chromium 手機模擬，另保留 375、390、393、440px、橫向及高字級回歸。這不是實體 iPhone Safari 驗收。

## 本輪發現並修正

| 問題 | 修正 |
| --- | --- |
| 行情空回應保留舊價，卻可能沒有快取標記 | 保留原報價及日期，顯示快取；更新防重入、提供忙碌狀態與讀屏播報 |
| 手動報價自訂驗證失敗，錯誤訊息在對話框背後 | 對話框內顯示錯誤，加入價格及股數上限 |
| 任意白／黑自訂主題造成字與底同色 | 調整實際主題色與按鈕前景，維持可讀對比；所選原色仍保留在偏好 |
| 淺色模式說明文字、上漲數字對比偏低 | 加深文字色，維持台股紅漲綠跌；正負號也呈現狀態 |
| 零股勾選與圖表署名連結點擊區不足 44px | 擴大標籤／連結至至少 44px，保留 TradingView 署名與真實連結 |
| 鍵盤視窗位移時，欄位可能不在可見區 | 使用 visualViewport 高度與 offsetTop，聚焦欄位捲入視窗；背景鎖定、inert、焦點循環及關閉後還原 |
| 加權指數卡片點擊後跳到自選頁，意義不符 | 改成純資訊卡；真正股票卡片才導向該標的分析 |
| PWA 第一次取得控制權會自動重新整理 | 首次安裝不重整，避免打斷輸入與捲動；使用者同意版本更新後才重新載入 |
| 日期化費率未用於預估賣出 | 依估值日選費率；歷史買入成本保留原交易快照，新增財務回歸測試 |

## 五頁檢查範圍

| 頁面 | 檢查 |
| --- | --- |
| 總覽 | 長名稱、持倉負數、卡片尺寸、更新中保留原數值、固定導覽、資訊卡與可點卡的區分 |
| 自選 | 代號／名稱搜尋、清除、星號增刪、選股導向、手動報價、錯誤提示 |
| 分析 | K 線自適應寬度、日週月切換、CSV、報價更新不重建圖表／改變捲動位置、試算滑桿與精確輸入、套用股數 |
| 持倉 | 買進、減碼、股利、超賣拒絕、刪除確認／取消、費稅與損益、備份、對話框焦點與縮小視窗 |
| 設定 | 深淺色、白／黑及一般自訂色、費率保存、JSON 匯出／匯入、CSV 驗證、手動價管理、安裝說明 |

所有頁面檢查卡片與主要數字溢出、觸控區、底部導覽避讓，並輸出淺／深色視窗截圖與完整捲動內容診斷圖。保留的測試行情、交易都是明確標記的**合成驗收資料**，不是使用者持倉，也不是本次取得的市場行情。

## 按鈕功能與證據

已逐項檢查事件處理，沒有展示用假按鈕。下列主要工作流程也有瀏覽器測試：

- 五個底部導覽、選股分析、搜尋與增刪自選。
- 新增買進／賣出／股利、超賣拒絕、刪除取消／確認、修改手動報價。
- 價格／股數／風險輸入即時計算、帶入價格、套用可承受股數、日週月圖表。
- 主題切換、自訂色、交易費率、JSON 備份往返、錯誤 JSON／CSV 不覆寫資料。
- 關閉按鈕、Escape、焦點循環及返回；行情更新、離線重開。

品牌返回總覽、SP 進設定、卡片連結、滑桿、手動價刪除、K 線匯入均有實際程式處理；外部官方及 TradingView 連結保留真實網址。PWA 更新按鈕只在有等待中版本時顯示，會送出 `SKIP_WAITING`；本次新增了首次安裝不重整的測試，但跨版本升級仍需部署後驗證。外部網站可達性不由按鈕事件檢查保證。

尚未開發的第二／三階段只顯示文字說明，不偽裝成可操作按鈕；未提供下單功能。

## 損益不是展示數字

財務模組獨立測試整／零股拆單、最低費用、股票與 ETF 稅、加權成本、部分出售、股利、費率生效日期及風險情境。瀏覽器也實際新增以下合成交易並驗算：

1. 1,000 股 × 100 元，六折手續費 85 元，成本 100,085 元。
2. 賣出 100 股 × 110 元，分攤成本 10,008.5 元，扣費稅後已實現損益 949.5 元。
3. 股利 500 元、剩餘 900 股；手動價格改為 90 元後，市值立即變成 81,000 元、未實現損益 −9,076.5 元。
4. 重新開啟保留資料，修改新交易費率不改寫歷史成本；超賣被拒絕。

這些驗證確認計算模型，沒有宣稱完成最新法規或券商對帳單認證。
