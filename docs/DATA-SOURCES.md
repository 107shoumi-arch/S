# 資料來源、更新與使用限制

本專案第一階段僅接入**官方每日收盤公開介面**，不宣稱提供盤中即時報價。應用程式中不預載示範行情；測試檔中的人工數值只供自動測試。免費介面不等於取得可轉售或商業散布的授權。

## 介面與官方文件入口

| 用途 | 官方介面 / 文件入口 | 本專案行為 |
| --- | --- | --- |
| 上市股票、ETF 收盤 | [TWSE OpenAPI](https://openapi.twse.com.tw/) 的 `/v1/exchangeReport/STOCK_DAY_ALL` | 保留官方 Date、ClosingPrice、Change、TradeVolume；無日期或有效收盤價即拒絕該筆 |
| 上櫃股票、ETF 收盤 | [TPEx OpenAPI](https://www.tpex.org.tw/openapi/) 的 `/v1/tpex_mainboard_daily_close_quotes` | 保留 Date、Close、Change、TradingShares |
| 加權指數每日收盤 | TWSE `/v1/exchangeReport/FMTQIK` | 依官方交易日排序取最新資料，不以請求時間代替交易日 |
| 上市日 K / 成交量 | [TWSE](https://www.twse.com.tw/) `/exchangeReport/STOCK_DAY?response=json&date=YYYYMM01&stockNo=2330` | 最多取本月與前一月；未還原權息。上櫃歷史資料未接入 |

上述介面程式呼叫不需要 API 金鑰；本專案未加入任何付費行情服務。免費替代方式是使用者從合法來源取得 CSV 後匯入。FinMind 尚未整合，未假設其最新免費額度或付費方案。

## 本次官方文件及連線核對狀態

本次雲端機器的網路政策尚未放行官方目的地。實際透過平台 HTTPS 代理請求 `openapi.twse.com.tw` 得到 **CONNECT HTTP 403**，因此無法在本次機器核對最新官方文件、額度、授權全文、更新時刻及完整真實回傳格式。上列端點是實作的介面契約，**不代表本次已完成官方上游整合驗證**。解析器有使用明確標記的人工測試樣本測試；不可將解析器測試通過解讀為上游連線成功。

環境設定已由主代理登錄所需網域；設定草稿不會自動套用目前機器。需在環境設定儲存／套用後，再對 `/api/market` 和 `/api/history?symbol=2330&market=TWSE` 檢查實際資料、來源及交易日，並從上列官方入口確認當前條款與資料欄位。本次不宣稱已讀到被阻擋的官方文件。

公開部署前，請核對各官方入口最新的「資料使用／授權條款」、流量限制與散布規則；本專案不提供授權法律保證。若官方條款不允許目標用途，應改用正式授權來源。此為尚未完成的外部驗證，不影響離線計算器與使用者資料匯入。

## 更新、快取與時間

- 行情來源是每日收盤，不是盤中即時；官方何時完成當日更新，以實際回傳交易日為準，休市日保留前一交易日。
- 伺服器每 15 分鐘最多重新擷取一份完整市場資料，並合併同時請求。單次 HTTP 請求 15 秒逾時。此為本 App 的節流策略，不是官方額度承諾。
- `asOf` 是資料本身的日期；`fetchedAt` 只是下載時間。日期精度資料不捏造小時／分鐘。瀏覽器與伺服器快取都保留原始來源及日期。
- 上游暫時失敗時允許顯示最後一份成功的官方快取，回傳 `cached: true` 及錯誤訊息，不把舊價格改標為今日／即時。
- 伺服器檔案快取位於忽略追蹤的 `.cache/official-market.json`，唯讀部署改用記憶體；瀏覽器備份由前端管理。無快取、上游不可用時顯示無行情，不顯示零元行情。
- 目前不支援除權息調整、股票分割、停止交易、改代號自動調整；歷史圖表不可直接用作含息報酬或正式回測。
- ETF 類型依代號作初步辨識，使用者建立持倉時須核對商品種類。債券 ETF 的實際免稅資格應依標的與規則生效日核對，不能只靠代號推論稅務適用。

## 使用者行情 CSV

以下為 `src/lib/market-import.ts` 中 `parseQuoteCsv` 的匯入格式。是否提供畫面上傳入口，以設定頁實際提供的功能為準；勿將行情 CSV 與圖表的日 K OHLCV CSV 混用。程式端可直接呼叫此函式驗證匯入資料。

欄位名稱：`symbol,name,price,asOf,market,kind`；可另外提供 `change,volume`。`market` 為 `TWSE` 或 `TPEx`；`kind` 為 `stock`、`etf` 或 `bond-etf`。`price` 為每股新台幣價格；`volume` 為成交股數。日期為 `YYYY-MM-DD` 或含時區的 ISO 時間。千分位數字需用雙引號括起。

範本只含欄位，不含任何模擬行情：

```csv
symbol,name,price,asOf,market,kind,change,volume
```

匯入價格永遠標記「使用者匯入（未經官方驗證）」，不會變成官方價格。每股價格限 0.01 至 100,000,000 元、最多兩位小數，與損益計算器契約一致。匯入器拒絕未來／不存在的日期、無效價格、缺漏必要欄位、重複代號及非整數成交股數。使用者自行對照來源後才應用於損益判讀。

## 後續適配層

`market-types.ts` 定義共用 Quote / Candle 契約；`market.ts` 是官方來源伺服器適配器；`market-import.ts` 是瀏覽器匯入器。後續可加入具有授權與正確時區的盤中提供者，並保留不同的頻率、來源及延遲欄位，不讓 AI 自行補值。
