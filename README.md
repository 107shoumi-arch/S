# StockPilot TW

iPhone 優先的台股與台灣 ETF 個人投資工具。第一階段提供官方行情介面、個人持倉損益與風險試算；不提供自動下單。

採用 Next.js、React、TypeScript、Lightweight Charts 與 PWA。行情由伺服器讀取官方公開資料，持倉保存在使用者自己的瀏覽器。第一階段不需要 AI 金鑰、資料庫或付費行情服務；先減少部署與維護負擔，後續可透過資料適配層擴充資料來源及同步儲存。

## 啟動專案

需求：Node.js 24、npm。第一次安裝：

```bash
cd /workspace/S
npm ci
npm run dev
```

在執行程式的電腦瀏覽器開啟終端機顯示的本機位址。雲端環境的 localhost 不是可供 iPhone 開啟的公開網址；手機使用方式見 [部署說明](docs/DEPLOYMENT.md)。

正式模式：

```bash
npm run build
npm run start
```

程式預設使用 3000 埠；請勿在同一埠同時執行開發與正式伺服器。

## 使用方式

底部有五個主要頁面：

- **總覽**：查看行情狀態、持倉市值、投入成本、損益與資料提醒。尚未輸入持倉或取不到行情時會顯示對應狀態。
- **自選**：以代號或中文名稱搜尋官方資料中的上市、上櫃股票及 ETF，加入自己的觀察清單。
- **分析**：查看選取標的及可取得的歷史行情；使用可調整的價格與風險參數試算損失、獲利及部位大小。第一階段不將試算值當成買賣訊號。
- **持倉**：記錄買入、賣出與已收到股利；每筆交易的股數是「股」，不是「張」（一般 1 張為 1,000 股）。確認價格、日期、交易種類與費用設定後儲存。
- **設定**：切換主題、調整交易費用、匯出或匯入備份，以及查看安裝與資料說明。

已實現損益採移動加權平均成本分攤；未實現損益、預估全部賣出淨損益及含股利總報酬分開呈現。手續費折扣以實際券商約定為準，最低手續費及取整方式也需與自己的券商對照。股票、股票型 ETF 與債券 ETF 的交易稅及適用日期有別；不能因代號以 `00` 開頭就一律套用免稅。

行情取得失敗時，可使用有日期標記的手動報價繼續做個人試算。手動輸入價格不是官方行情；錯誤價格會直接影響計算結果。調整價格、股數與風險條件後，試算會即時更新，無須重新整理整頁。

分析頁也可匯入自己的日 K CSV，欄位順序為 `date,open,high,low,close,volume`。日 K 匯入只用於目前工作階段的圖表，不會變更最新報價或持倉成本；切換標的或重新載入後須重新匯入。週 K 與月 K 由可取得的日 K 彙整，資料期間不足時不能當作完整長期歷史。

設定頁可另外匯入行情 CSV，必要欄位是 `symbol,name,price,asOf,market,kind`，欄位含義與格式見 [資料來源說明](docs/DATA-SOURCES.md)。這些價格可用於持倉估值，永遠標記為使用者匯入。這與分析頁的日 K CSV 是不同用途。

## 行情與資料時間

- 本專案使用**收盤／日資料**，不是即時報價。每筆行情顯示來源與資料日期；「取得時間」不代表「成交時間」。休市日可能顯示上一交易日資料。
- 官方資料無法存取、格式改變或部分欄位缺漏時，畫面應顯示錯誤、缺漏或具日期的快取，不使用模擬行情填補。
- 歷史 K 線需要足夠且有效的 OHLC 資料；資料不足時顯示空狀態，不推算不存在的價格。
- 資料來源、授權核對與更新頻率見 [資料來源說明](docs/DATA-SOURCES.md)。本次雲端環境若擋住官方網域，必須先在環境設定保存網域變更，部署主機亦須允許連線。

核心損益與風險試算不需要 AI API。後續 AI 模組只解釋已驗證的輸入；第一階段沒有呼叫模型產生投資建議。

## 在 iPhone 加入主畫面

1. 依 [部署說明](docs/DEPLOYMENT.md) 取得實際的 **HTTPS** 網址。
2. 用 iPhone 的 **Safari** 開啟該網址，等待首次載入完成。
3. 點 Safari 的「分享」按鈕，選擇「加入主畫面」。若未顯示，向下捲動分享選單。
4. 確認名稱「StockPilot TW」，點「加入」，再從主畫面圖示開啟。
5. 檢查頂部狀態列及底部 Home Indicator 沒有遮住內容；完整驗收見 [手機驗收清單](docs/ACCEPTANCE.md)。

第一次使用需要網路。離線介面只能使用已下載的資源及明確標示時間的資料；離線不會更新行情。上線後重新開啟 App 取得最新資源，並留意更新提示。

## 個人資料與備份

持倉與設定保存在目前瀏覽器的本機儲存空間，不會自動跨裝置同步。Safari、主畫面 App、其他瀏覽器及不同網址可能使用不同儲存空間。請定期在設定中匯出 JSON 備份，再將檔案存放於自己的安全位置；匯入前先備份現有資料。

清除網站資料、私密瀏覽或刪除 App 可能使資料消失。公開部署不等於開放持倉給其他人，但共用同一裝置與瀏覽器設定檔的人可能讀到本機資料；第一階段沒有登入、端對端加密或雲端備份。

## 目前範圍與後續架構

第一階段目標是可操作的 PWA、搜尋及行情介面、持倉交易記錄、交易成本計算與風險試算。官方市場介面與財務計算模組分離，便於加入新資料來源與策略測試。

以下不屬於本階段已完成的功能：

- 第二階段：獨立 EntryExitEngine、可回測的進出場條件、短線／波段指標與策略。
- 第三階段：完整 ETF 成分股及含息資料、長期分析、策略回測、AI 報告。
- 第四階段：背景監控提醒、同步儲存、效能優化及正式部署後的完整驗收。

真實 iPhone Safari、正式公開網址與完整上市／上櫃資料可用性，必須在部署及實際資料請求後分別確認，不能由本機畫面推定。投資試算是依輸入及費率規則計算的情境，不保證成交、停損執行或未來報酬。
